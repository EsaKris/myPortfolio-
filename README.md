## 🧑‍💻 About This Project

This portfolio is built to represent a **Full-Stack Python/Django developer** — not just a generic template. Every component has been redesigned from scratch with a cohesive dark editorial aesthetic: emerald accents, glass surfaces, `Syne` display typography, and deliberate motion design.

It's fast, responsive, and built to make an impression.

---

## 🛠 Tech Stack

| Layer | Technologies |
|---|---|
| **Frontend** | React.js, Vite |
| **3D Graphics** | Three.js, React Three Fiber, Drei |
| **Styling** | Tailwind CSS, Framer Motion |
| **Fonts** | Syne (headings), DM Sans (body) |
| **Contact** | WhatsApp deep-link integration |
| **Deployment** | Render |

## ✨ Component Breakdown

### `Navbar`
- Frosted glass effect on scroll with emerald border
- Logo with glow badge, "Hire me" CTA chip
- Smooth mobile drawer with dot-state indicators

### `Hero`
- Live terminal typewriter running real Django/Python commands
- Cursor-tracking glow using `useSpring`
- Floating tech orbs (Python, Django, React, Docker, PostgreSQL, REST API)
- Stat chips: experience, projects, uptime

### `About`
- Split bio + quick-facts sidebar card
- Inline tech keyword highlights
- Tilt cards with glare effect and hover accent lines

### `Experience`
- Interactive accordion list replacing the heavy vertical timeline
- Sticky detail panel on desktop (lg+ screens)
- Expandable role cards with smooth height animation

### `Tech`
- 3D rotating tech balls (Three.js)
- Tooltip on hover + emerald glow filter per ball

### `Works`
- Hover-reveal GitHub button with fade + scale animation
- Image zoom effect on card hover
- Clean tag chips and in-card source link

### `Feedbacks`
- Stats header row (reviews, avg rating, recommend %)
- Star ratings per card
- Online presence dot on reviewer avatars

### `Contact`
- 2-column name/email layout
- Live character counter on message field
- Contact method chips (WhatsApp, response time, remote)
- Animated success banner on submission
- WhatsApp deep-link opens pre-filled message

### `CanvasLoader`
- Spinner ring + animated progress bar replacing the bare spinner

## 🎨 Design System

All components share a unified token set:

```
Accent color:     #10b981  (emerald)
Background:       #020b12  (near-black)
Surface:          rgba(255,255,255,0.03–0.07)  (glass)
Display font:     Syne 700/800/900
Body font:        DM Sans 400/500/600
Label style:      font-mono, tracking-widest, uppercase
```

Add these to your `index.html` for the font imports:

```html
<link
  href="https://fonts.googleapis.com/css2?family=Syne:wght@700;800;900&family=DM+Sans:wght@400;500;600&display=swap"
  rel="stylesheet"
/>
```

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/EsaKris/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

> No `.env` file required — contact form uses WhatsApp deep-links instead of EmailJS.
